# Focus 2 • Unit 6: Work — Interactive Lab (Grade 10)

Інтерактивний навчальний вебдодаток з англійської мови для учнів **10 класу** за підручником **Focus 2 (Unit 6: Just the Job!)**.

## Що всередині:
1. **Реєстрація учня** з вибором класу (`10-А`, `10-Б`, `10-В`, `10-Г`, `10-Д`, `10-Ж`, `10-К`).
2. **Завдання 1 (Drag & Drop):** Розподіл ключової лексики Unit 6 за категоріями (*Conditions & Pay*, *Personal Qualities*, *Career Actions*). Підтримує як перетягування мишею, так і сенсорне натискання на смартфонах.
3. **Завдання 2 (Drag & Drop):** Граматичний тренажер *Second Conditional* із заповненням пропусків.
4. **Завдання 3 (Симуляція):** Інтерактивна співбесіда на роботу (*Job Interview Simulation*) із миттєвим фідбеком від HR-менеджера.
5. **Завдання 4 (Use of English):** Відпрацювання різниці між *job / work* та сталих прийменників.
6. **Журнал спроб і завантаження PDF:** Автоматична фіксація кожної спроби та проміжного балу з можливістю завантажити готовий PDF-звіт на комп'ютер або телефон.

## Як опублікувати на GitHub Pages:
1. Створіть новий репозиторій на GitHub (наприклад, `focus2-unit6-work`).
2. Завантажте файл `index.html` (та папку `assets/`) у корінь репозиторію.
3. Перейдіть у **Settings → Pages → Build and deployment → Source: Deploy from a branch**, оберіть гілку `main` та папку `/ (root)` і натисніть **Save**.
